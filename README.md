# ✿ Pastel AI Studio v1.0.1

Codex CLI 연동 기반의 파스텔 톤 Windows 데스크톱 AI 채팅 클라이언트입니다.

## ✨ v1.0.1 주요 개선 사항 (Changelog)

1. **버전 관리 및 아이콘 적용 (`v1.0.1`)**
   - 창 제목, 사이드바 헤더, 설정 창, 내보내기 문서에 `v1.0.1` 버전 명시 및 앱 아이콘(`sch.ico`) 자동 로드
2. **사이드바 실시간 대화 검색 & 이름 변경**
   - `🔍 대화 제목·내용 검색…` 입력창을 통해 대화 제목과 메시지 본문을 실시간 필터링
   - 각 대화의 메시지 개수 표시 `(N)` 및 `✏️ 이름 변경` 버튼(또는 목록 더블클릭)으로 대화 제목 수정 지원
3. **말풍선 편의 기능 (복사 / 다시 생성 / 첨부 이미지 인라인 미리보기)**
   - 모든 말풍선에 `복사` 버튼 추가 (클릭 시 `복사됨 ✓` 시각적 피드백 제공)
   - 마지막 AI 답변(또는 실패·중단된 답변)에 `↻ 다시 생성` 버튼 추가
   - 사용자가 첨부한 이미지(`.png`, `.jpg`, `.jpeg`, `.webp`)를 말풍선 내부에 썸네일로 즉시 표시
4. **이미지 갤러리 & 이미지 저장 버그 수정**
   - 기존 버전에서 사용자 첨부 이미지가 갤러리 및 `이미지 저장` 대상에서 누락되던 문제를 수정하여, 대화 내 모든 첨부·결과물 이미지를 갤러리에서 크게 보고 저장 가능
5. **클립보드 캡처 이미지 바로 붙여넣기 (`Ctrl+V`) & 개별 첨부 삭제**
   - 화면 캡처(`Win+Shift+S` 등) 후 입력창에서 `Ctrl+V`를 누르면 자동으로 PNG 파일로 변환·첨부
   - 전체 첨부 취소뿐 아니라 `개별 첨부 삭제` 버튼으로 원하는 파일만 선택 제거 가능
6. **대화 전체 Markdown 내보내기 (`대화 내보내기`)**
   - 단일 답변 저장 외에 현재 대화 전체 이력을 깔끔한 Markdown(`.md`) 문서로 내보내는 기능 추가
7. **실시간 경과 시간 표시 (`⏱ N초 경과`)**
   - AI 답변 생성 중 상태 표시줄에 실시간 경과 시간 타이머를 표시하여 동작 상태를 명확히 확인
8. **맞춤 지침(시스템 프롬프트) 및 문맥 범위·추천 모델 설정**
   - `⚙️ 설정`에서 추천 모델 프리셋 선택, 문맥 유지 메시지 수(`2~64개`) 조절, 사용자 맞춤 지침(말투·답변 규칙) 저장 지원
9. **Codex CLI 자동 탐색 강화 및 `--ephemeral` 적용**
   - 환경변수 `PATH` 새로고침 전이라도 Windows 기본 설치 경로(`%LOCALAPPDATA%\Programs\OpenAI\Codex\bin\codex.exe` 등)를 자동 탐색
   - `codex exec` 실행 시 `--ephemeral` 옵션을 사용하여 불필요한 임시 세션 파일 누적 방지

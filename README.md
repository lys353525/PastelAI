## v1.0.2 변경 사항

### API 키 사용 방식 추가

기존에는 Codex CLI 로그인만 사용할 수 있었지만, 이제 설정에서 다음 두 가지 방식 중 하나를 선택할 수 있습니다.

1. **Codex CLI 로그인**
   - 기존 방식입니다.
   - `브라우저 로그인` 버튼으로 Codex 계정을 인증합니다.

2. **OpenAI 호환 API 키**
   - API 키를 입력하고 모델명을 지정합니다.
   - 기본 주소는 `https://api.openai.com/v1`입니다.
   - OpenAI 호환 API를 제공하는 다른 서비스는 해당 서비스의 Base URL을 입력할 수 있습니다.

API 키는 화면에서 가려져 표시되며 프로그램의 로컬 설정 파일에 저장됩니다. 다른 사람과 설정 파일을 공유하거나 API 키가 포함된 파일을 공개 저장소에 올리지 마세요.

## API 키 방식 설정 방법

1. 프로그램을 실행합니다.
2. 왼쪽 아래의 **설정 / ChatGPT 로그인**을 클릭합니다.
3. 사용 방식을 **OpenAI 호환 API 키**로 선택합니다.
4. API 키를 입력합니다.
5. 사용할 모델명을 입력하거나 목록에서 선택합니다.
6. OpenAI를 사용하면 Base URL을 그대로 둡니다.
7. 다른 호환 서비스를 사용하면 해당 서비스가 안내하는 Base URL로 바꿉니다.
8. **설정 완료**를 클릭합니다.

> API 키 방식은 모델명과 API 키가 모두 있어야 사용할 수 있습니다.

## 실행 파일

`dist/app/app.exe`를 실행하면 됩니다.

Codex CLI 방식으로 처음 사용하는 경우에는 `dist/app/Codex_Cli설치-처음 한번만 실행.bat`을 먼저 실행하세요.

## 개발 환경에서 실행

Python 3.11 이상과 필요한 패키지를 설치한 뒤 다음 명령을 실행합니다.

```bash
python app.py
```

구문 검사는 다음 명령으로 할 수 있습니다.

```bash
python -m py_compile app.py core.py codex_client.py
```

## 주의 사항

- API 사용 요금과 사용 한도는 선택한 서비스의 정책을 따릅니다.

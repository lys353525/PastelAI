# ✿ Pastel AI Studio 2.0 — Windows 개인용 LLM 채팅 프로그램

기존 Pastel AI Studio 프로젝트를 확장한 **파스텔 톤의 Windows GUI**입니다.

## 제공 기능

- 말풍선 채팅, 대화별 저장·불러오기 및 삭제
- OpenAI Responses API **실시간 텍스트 스트리밍** (중단 버튼 포함)
- Markdown 코드 블록 **Pygments 구문 강조**, 개별 코드 블록 복사·저장
- PDF, DOCX, TXT, CSV, 코드, PNG/JPG/WEBP 등 **파일 첨부**
- 파일 선택 또는 **드래그 앤 드롭** (채팅 입력창과 점선 영역)
- 이미지 생성(`gpt-image-1`), 말풍선 이미지 미리보기, **대화별 이미지 갤러리**
- 응답 원문 `.md`, 추출 코드 `.py`/`.js` 등, 생성 그림 `.png`, 업로드 파일 자동 보관
- **API 키 1회 입력** 후 Windows 자격 증명 관리자(Credential Manager)에 저장
- **⚙️ 설정**에서 API 키 교체·삭제 및 채팅 모델 변경
- 마지막 답변/코드/이미지 수동 내보내기와 대화별 결과물 폴더 열기

## 설치 및 실행 (Windows 10/11)

1. Python 3.10 이상의 64비트 버전을 설치하세요. 설치 시 `py` 런처도 활성화하세요.
2. ZIP 압축을 풀고 **`run_windows.bat`** 을 더블클릭하세요.
3. 최초 실행 시 필요한 패키지를 설치합니다. 설치에는 인터넷 연결이 필요합니다.
4. 앱이 뜨면 **⚙️ 설정**에서 자신의 **OpenAI API 키**를 입력하고 `API 키 저장 / 변경`을 누릅니다.
5. `설정 완료`를 눌러 채팅을 시작합니다. 다음 실행부터는 키를 다시 입력할 필요가 없습니다.
6. API 키를 바꾸고 싶다면 언제든 **⚙️ 설정 / API 키 변경** 버튼을 누르세요.

> OpenAI의 ChatGPT 웹 구독과 API 요금/잔액은 별개입니다. 이미지 생성도 API 과금 및 계정별 모델 권한의 영향을 받습니다.

### EXE 만들기

Windows에서 **`build_exe.bat`** 을 실행하면 `dist\PastelAIStudio.exe` 파일을 생성합니다. EXE 빌드 자체는 Windows 환경이 필요합니다. 단일 EXE를 다른 Windows PC에서 실행해도 API 연결을 위해 인터넷이 필요합니다.

## 파일 보관 구조

사용자 홈 폴더의 `PastelAIStudio`에 대화가 보관됩니다. 예를 들어:

```
C:\Users\<Windows사용자>\PastelAIStudio\
  chats.json                # 대화 텍스트 및 결과물 경로 (API 키 없음)
  settings.json             # 기본 모델만 저장 (API 키 없음)
  chats\
    <대화ID>\
      attachments\          # 사용자가 첨부한 원본 파일 복사본
      answers\              # AI 답변 Markdown 파일 (.md)
      code\                 # 코드 블록 (.py, .js, .html ...)
      images\               # 생성한 이미지 (.png)
```

**보안 관련:** API 키는 위 파일들에 저장되지 않습니다. Windows 자격 증명 관리자에 등록되며 Windows 사용자 계정 권한이 적용됩니다. 반면 **채팅 내용, 첨부파일, 결과물은 로컬 폴더에 일반 파일로 저장되므로 암호화되지 않습니다.** 민감한 파일을 첨부했다면 앱의 '대화 삭제'를 통해 보관 파일을 삭제하거나 Windows 파일 암호화 기능을 사용하세요. 삭제된 내용의 복구 가능성은 파일 시스템 정책에 따릅니다.

### 채팅 및 생성

- `Ctrl + Enter`로 메시지 전송
- 📎 영역/입력창에 파일 끌어놓기 (최대 **8개**, 각 파일 **12MB 이하**)
- `.pdf`와 `.docx` 파일은 텍스트로 추출해 전송하며, **스캔 PDF OCR은 미지원**
- 채팅에 첨부한 파일은 대화 폴더에 복사되어 이후 메시지의 문맥으로도 사용됩니다.
- `🎨 이미지 생성: ON` 후 이미지 설명을 전송하면 그림을 생성합니다. 이미지 생성 모드에서 첨부파일은 사용하지 않습니다.
- 생성한 그림은 **이미지 갤러리**에서 크게 보고 PNG로 내보낼 수 있습니다.
- 코드 블록 오른쪽에서 **복사** / **코드 저장**이 가능합니다.
- 결과물은 **자동 보관**됩니다. 수동 내보내기는 별도의 복사본을 만들 때 사용하세요.
- 생성 중에는 대화를 바꿀 수 없으며, **중단** 버튼으로 스트리밍 종료를 요청할 수 있습니다. 이미지 생성은 서버 응답이 도착한 다음 중단 처리됩니다.

## API 연결 및 개인정보

- OpenAI SDK를 통한 외부 API 호출이므로 **인터넷 연결**, 사용 가능한 키, 해당 모델 접근 권한이 필요합니다.
- 선택한 이전 대화 일부(최근 최대 16개 메시지) 및 그 대화의 첨부파일이 문맥 유지를 위해 다시 API로 전송됩니다. 긴 문서의 텍스트는 최대 100,000자로 제한됩니다.
- 이미지 생성 요청은 별도 이미지 API를 사용합니다.
- 코드/답변은 LLM의 출력으로, 실행 전에 반드시 내용을 확인하세요.
- 지원 모델은 사용 가능 모델 변경에 따라 설정에서 직접 수정할 수 있습니다.

## 포함 파일

- `app.py`: Windows PySide6 GUI, 스트리밍 및 이미지 갤러리
- `core.py`: 대화 파일, 첨부, 자동 보관, 코드 블록 파서
- `credential_store.py`: Windows 자격 증명 관리자 전용 API 키 저장
- `requirements.txt`: 필수 파이썬 패키지
- `run_windows.bat`: 가상 환경/의존성 설치 및 실행
- `build_exe.bat`: PyInstaller EXE 생성
- `tests/`: 핵심 저장 및 경로 검증 테스트

## 개발 및 확인 상태

Python 구문 검사와 파일 저장/코드 추출/경로 검증에 대한 자동화 테스트가 포함되어 있습니다. **이 제작 환경은 Windows가 아니며 PySide6 런타임 설치가 제한되어 있기 때문에 실제 Windows 화면, WinCred 자격 증명 연동 및 실시간 OpenAI 호출은 직접 실행하여 검증하지 못했습니다.** 문제 발생 시 명령 프롬프트에서 `run_windows.bat`을 실행해 표시되는 오류 로그를 확인할 수 있습니다.
